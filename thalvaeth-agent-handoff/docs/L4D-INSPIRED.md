# Pacing (not creature names)

L4D informs **solo tension** — valleys, peaks, noise, one nasty rule per threat. **Creature names/tags** are humanoid Thal'vaeth terms — see [CREATURES.md](CREATURES.md).

| Feel | Thal'vaeth tag |
|------|----------------|
| Don't wake it | **Sleeper** |
| Drop from above | **Rafter** |
| Scream → horde | **Caller** |
| Hook / pull | **Snare** |
| Edge pace | **Stalker** |
| Wall block | **Brute** |
| Fodder packs | **Scavenger** |

Stress Director: invisible, no pressure meter v1. Safe pockets: sparse, once per run.
